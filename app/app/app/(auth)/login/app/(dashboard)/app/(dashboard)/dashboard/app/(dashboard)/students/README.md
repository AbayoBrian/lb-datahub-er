# LB DataHub School ERP

## Intelligence for Every School

A cloud-native, AI-powered School Operating System for managing every aspect of an educational institution.

## Features

- 🏫 Multi-school support
- 👨‍🎓 Student Information System
- 👨‍🏫 Staff Management
- 📚 Academics (CBC, 8-4-4, Cambridge)
- 📊 Assessments & Examinations
- 💰 Fee Management with M-Pesa
- 📈 Analytics & Business Intelligence
- 🤖 AI-Powered Insights
